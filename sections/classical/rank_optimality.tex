\label{section:rank-opt}
In this section we present a proof for Ranking Optimality (\autoref{thm:rank-optimal}) by \cite{karp}. The main vehicle for this is Yao's lemma with a construction of a class of matching instances. Using the lemma, performance of any algorithm is bounded by the performance of a deterministic greedy algorithm on a randomized instance, which we will prove is equivalent to the performance of RGA on a specific instance, which we will approximate using differential equations

\begin{algorithm}
	\caption{RGA}
	\label{alg:RGA}
	\begin{algorithmic}
		\item on Arrival of vertex $v$: match it with a random available offline neighbor
	\end{algorithmic}
\end{algorithm}

\begin{definition}
	bipartite online matching instance $(n,\sigma)$ where $\sigma$ is a permutation of $[n]$ is constructed as follows:
	\begin{itemize}
		\item offline vertices are $u_i$ for $i\in[n]$
		\item online vertices are $v_j$ for $j\in[n]$
		\item $u_i,v_j$ are connected iff $\sigma(i)\leq j$
	\end{itemize}
\end{definition}
The collection of all $n!$ $(n,\sigma)$ instances is $I$. $U(I)$ is the uniform distribution over $I$. $I^\star$ is $(n,(1,\dots,n))$, the original instance without permutation
\begin{figure}[H]
	\centering
	\input{figures/semionline/optimal.tikz}
	\caption{Instance $I^\star$}
\end{figure}
Instance $I=(n,\sigma)$ is the instance $I^\star$ after offline agent order is reshuffled according to $\sigma$
notice that perfect matching is achieved only if $u_i$ is matched with $v_{\sigma(i)}$ for all $i\in[n]$\\

\begin{lemma}
	\label{dga-rga-equiv}
	Let $\mathrm{DGA}$ be a greedy deterministic algorithm.\\
	The expected performance of $\mathrm{DGA}$ on a random instance from $U(M)$ bounds the expected performance of $\mathrm{RGA}$ on $I^\star$\\
	\[\underset{m\sim U(M)}{\E}[|\mathrm{DGA}(m)|]=\E[\mathrm{RGA}(M^\star)]\]
\end{lemma}
\begin{proof} To prove the lemma we first need to prove two claims:\\
% -- ??? -- ??? -- ???
	\begin{claim}[1]
		for $\mathrm{DGA}$ on $(n,\sigma)$ as well as $\mathrm{RGA}$ on $I^\star$ if at time $t$ there are $k$ eligible offline vertices then they are equally likely to be any set of $k$ vertices among the last $n-t+1$
	\end{claim}
	\begin{claim}[2]
		for each $k$ the probability that there are $k$ eligible offline vertices at time $t$ is the same for $\mathrm{DGA}$ on $(n,\sigma)$ as well as $\mathrm{RGA}$ on $I^\star$
	\end{claim}
	% -- ??? -- ??? -- ??? Think this is supposed to be 'all rows are equally likely to be eligible' since the n-t+1 applies only to RGA
	Claim 1 is proven with induction over time - tha amount of online vertices that have already arrived. Note that induction base at step 0 is trivial since all offline vertices are eligible.\\
	Note that a vertex is available if it can still be matched ie isn't matched and isn't unmatchable
	\begin{proof} of Claim 1\\
		for $\mathrm{RGA}$.
		\[\Pr[S\ \text{available at time }t+1]=\sum\limits_{v\not\in S}\Pr[S\cup\{v\}\ \text{available at time }t]\Pr[v\ \text{picked at time }t]\]
		and since probabilities at time $t$ are equal and the probability of choosing all $v$ is either equal or $0$ then the condition is maintained\\
		for $\mathrm{DGA}$, since it is deterministic and the algorithm can't read labels, then the subsequent matching is determined by the current available set, which is uniformly random, implying the next one is also uniformly random.
	\end{proof}
	\begin{proof} of Claim 2\\
		It is a direct consequence of Claim 1. If the offline vertices eligible for matching are uniformly distributed in both cases, then the probability that a vertex becomes unmatchable is also equal for both algorithms, and that probability is the probability that the amount oa eligible vertices decreases by $2$ instead of $1$
	\end{proof}
	The lemma follows directly from Claim 2 since the size of the matching is equal to the amount of steps required for there to be no eligible vertices
\end{proof}

By using Yao's lemma we receive the following: for any algorithm $\mathrm{ALG}$
\begin{equation}
	|\mathrm{ALG}(M)|:=\underset{m\in M}{\min}\E[|\mathrm{ALG,m}|]\leq \underset{\mathrm{DALG}}{\max}\underset{m\sim U(M)}{\E}[|\mathrm{DALG}(m)|]=\E[|\mathrm{RGA}(M^\star)|]
\end{equation}

Since (as proven in the previous section) only instances with perfect matchings need be considered in competitiveness analysis, competitiveness of all algorithms is upper bounded by $\E[|\mathrm{RGA}(M^\star)|]/n$

Now, all that is required to prove the following lemma 

\begin{lemma}
	\label{rga-performance}
	$\E[|\mathrm{RGA}(M^\star)|]\leq n(1-\frac{1}{e})+o(1)$
\end{lemma}
The rest of this section is the proof of this lemma.


Let $\rem(t)$ be the random variable representing the number of remaining online vertices and $\avl(t)$ be the number of offline vertices available for matching, at the time $t$. $\Delta f$ is used conventionally, as the change of $f(t)$ over $t$.\\
$\Delta \rem$ is always $-1$ while $\Delta\avl$ is either $-1$ or $-2$. It is only $-2$ if $n_t$ is being matched and $f_t$ is available (event $A_t^1$) and it isn't matched to $n_t$ (event $A_t^2$) since $f_t$ becomes unmatchable.\\
Note that $\rem$ is essentially a clock ticking backwards since it has value $n-t$

$\Pr[A^1_t|\avl,\rem]=\frac{\avl}{\rem+1}$ since from Claim 1 from \autoref{dga-rga-equiv} we know that all $\avl$ sized subsets are equally likely to be the available subset\\
$\Pr[A^2_t|\avl]=1-\frac{1}{\avl}=\frac{\avl-1}{\avl}$ since matched vertex is chosen randomly\\
Since both events are independent $\Pr[A^1_t\land A^2_t]=\frac{\avl-1}{\rem+1}$\\
$\E[\Delta\avl]=(-2)\frac{\avl-1}{\rem+1}+(-1)(1-\frac{\avl-1}{\rem+1})$

finally
\begin{equation}
	\label{rank-opt-e-avl}
	\E[\Delta\avl]==-1-\frac{\avl(t)-1}{\rem(t)}
\end{equation}
implying $\frac{\mathrm{E}[\Delta\avl]}{\mathrm{E}[\mathrm{\Delta\rem}]}=1+\frac{\rem(t)-1}{\avl(t)}$ since $\Delta\rem$ is always $-1$\\
Though this is a discrete Markov Chain, we can approximate it by treating it as a continuous function, whose rate of growth is already known. Moreover, this approximation's accuracy increases as $n$ increases
\begin{equation}
	\label{rank-opt-diff}
	\frac{d\avl}{d\rem}=1+\frac{\avl-1}{\rem}
\end{equation}
We also have the initial conditions, $\avl=\rem=n$, meaning we can find an approximating equation by solving $\autoref{rank-opt-diff}$

\begin{align*}
	\frac{d\avl}{d\rem}=1+\frac{\avl-1}{\rem} & \text{ can be rewritten as}\\
	\frac{d\avl}{d\rem}-\frac{\avl}{\rem}=\frac{\rem-1}{\rem} & \text{ multiply both sides by }m(\rem)=e^{\int -1/\rem \,d\rem}\\
	\frac{\frac{d\avl}{d\rem}}{\rem}+\frac{d}{d\rem}\left(\frac{1}{\rem}\right)\avl=\frac{\rem-1}{\rem^2} & \text{ apply product rune to LHS}\\
	\frac{d}{d\rem}\left(\frac{\avl}{\rem}\right)=\frac{rem-1}{\rem^2} & \text{ integrate both sides}\\
	\int\frac{d}{d\rem}\left(\frac{\avl}{\rem}\right)=\int\frac{\rem-1}{\rem^2}\\
	\frac{\avl}{\rem}=\frac{1}{\rem} + \ln\rem + c & \text{ apply initial condition }\avl=\rem=n\\
	1=\frac{1}{n}+\ln n + c\implies&\\
	\avl=1+\rem\left(\ln\rem-\ln n+1-\frac{1}{n}\right)
\end{align*}

giving us the final approximation

\begin{equation}
	\label{rank-opt-final}
	\avl=1+\rem\left(\frac{n-1}{n}-\ln\frac{\rem}{n}\right)
\end{equation}

Bearing in mind that the initial Markov chain doesn't perfectly emulate the last step, we substitute $\rem=1$ instead $\rem=0$ and from \autoref{rank-opt-final} we receive that, when only 1 online vertex has yet to arrive, the number of remaining columns is $n\frac{1}{e}+o(1)$. Bearing in mind that the last arriving vertex will affect the performance by at most 1, the expected size of the final matching is $n\left(1-\frac{1}{e}\right)$
