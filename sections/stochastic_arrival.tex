\begin{definition}[iid Model]
	In the iid model the algorithm always knows a set of offliene vertices $U$, but there is no determined set of online vertices $V$. Instead, there is a set $V'$ of vertex 'archetypes' consisting of a neighborhood $N\subseteq U$ and a probability $p$. When a new vertex $v$ arrives, for each $(N,p)\in V'$ $v$ has of $p$ to have neighborhood $N$. The archetype set $V'$ is known to the algorithm. The amount of vertices that will arrive in total, $n$, is also known.
\end{definition}
We note two things here:
\begin{enumerate}
	\item obviously, $\sum\limits_{(N,p)\in V'}p=1$
	\item This model is still a game, but the adversary has been stripped of almost all agency and now cannot even control the final graph
\end{enumerate}

We will present the proof of two theorems in this chapter:

\begin{theorem}
	No algorithm has a competitiveness of $1-\epsilon$ for an arbitrary $\epsilon$ in the iid model
\end{theorem}
meaning that there is no perfect algorithm, and
\begin{theorem}
	\label{thm:sa-alg}
	The stochastic arrival model is strictly easier than the Semi-Online model since there is an algorithm with competitiveness $\approx 0.67029$
\end{theorem}
In actuality, there is an algorithm with a competitiveness of $0.702$, better than the proven competitiveness of Ranking in the random arrival model. However, this algorithm is very complicated so we will instead showcase a simpler one to show that the $1-\frac{1}{e}$ barrier can be beaten
