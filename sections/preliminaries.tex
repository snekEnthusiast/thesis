\paragraph{Graphs}
A graph $G=(V,E)$ is a structure composed of a set of vertices $V$ and a set edges $E$ which are unordered pairs of vertices. A degree of $v\in V$ $\deg(v)=|\set{u\in V|(u,v)\in E}|$ is the amount of edges from $v$.
A full graph, where $E=\set{(v,u)|v,u\in V}$ contains all possible edges is also called a clique. An anticlique is a graph where $E=\emptyset$ is empty. A bipartite graph $G=(U,V,E)$ is comprised of two anticliques, ie $E\cap V\times V=\emptyset$, $E\cap U\times U=\emptyset$.
\paragraph{Matching}
A matching $M$ is a set of edges with no common endpoints. A vertex is matched if it is en endpoint of some $e\in M$. An edge is matched if it is in $M$. A matching $M$ is maximal when it is maximal in terms of inclusion, ie there is no matching that is a superset of $M$. A matching is maximum, denoted $M^\star$, if it is maximal in terms of cardinality, ie there is no matching containing more edges. A matching is perfect if all vertices are matched. In the context of some matching $M$, an alternating path is a sequence of vertices $(v_1,\dots,v_k)$ such that $(v_i,v_{i+1})\in M\implies(v_{i+1},v_{i+2}\not\in M)$ and vice versa, forming a path of edges that alternately are and are not part of $M$. An augmenting path is an alternating path where the first and last edge are not in $M$. Berge's theorem states that a matching is maximum iff there are no augmenting paths. To switch an augmenting path is to remove it's second, fourth etc edges from $M$ and add the first, third, etc, expanding the matching by 1 edge.
\paragraph{Online Algorithms}
An Online Algorithm is one that doesn't have access to the entire input at all times, but instead receives it in a serial fashion. Decisions regarding that data usually must be made immediately and irrevocably. In this way an online problem may be considered a game between the algorithm and an adversary whose goal is to force the algorithm to make the worst decisions possible. An adversary always knows how the algorithm operates, but may not know the result of random choices that the algorithm makes. If it does, it's adaptive and if not it is oblivious. Competitiveness is the measure of performance for online algorithms and is $\inf\limits_{\text{instance}}\inf\limits_{\text{arrival order}}\frac{|\mathrm{ALG}|}{|\mathrm{OPT}|}$ a bound on the size of the solution found by the algorithm divided by the best solution. In the context of online algorithms time $t$ is the amount of data packets that have arrived. Yao's lemma, also known as Yao's minimax principle, is a vehicle for relating the performance of randomized algorithms to deterministic algorithms for certain classes of algorithms and certain measurements of performance
\paragraph{Linear (and other) Programming}
A linear program is a problem of maximizing a linear function under linear constraints, defined as 'minimize $c^Tx$ subject to $Ax\leq b$'. A feasible solution is a value of $x$ that satisfies program constraints. Every linear program (the primal program) has a dual program associated with it, defined as 'maximize $b^Ty$ under $A^Ty\geq c, y\geq 0$'. An important property of the dual program is Weak Duality: for all feasible primal, dual solutions $x,y$, $c^Tx\leq b^T y$. Meaning any feasible dual solution is a bound on any feasible primal solution. An integer program is a linear program with the additional constraint $x\in\mathbb{Z}^n$.
A totally unimodular matrix is one whose every square submatrix has a determinant in $\set{-1,0,1}$. It is knon that if $A$ is totally unimodular and $b$ is integer then for any optimization direction $c$, the corresponding linear program has an optimum in $\mathbb{Z}^n$.
