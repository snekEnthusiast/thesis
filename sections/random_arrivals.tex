As shown before, relatively simple algorithms achieve the optimal competitiveness of $1-\frac{1}{e}\approx0.632$. A natural question is to ask how to break this barrier. This is possible with a relatively small model change.

\begin{definition}[Random Arrival model]
	The random arrival model is identical to the semi-Online model except for one crucial difference - the order of arrival of vertices is random instead of adversarial. All other details remain identical
\end{definition}

In this section we will prove that both Ranking and RGA perform strictly better in the Random Arrival model than in the Semi-Online model

\begin{theorem}
	\label{thm:rga-ra-comp}
	In the random arrival model, any deterministic algorithm that matches vertices by prioritizing those first in an arbitrary permutation $\sigma$ has a competitiveness of $1-\frac{1}{e}$
\end{theorem}

\begin{theorem}
	\label{thm:rank-ra-comp}
	In the random arrival model, Ranking has a competitiveness of at least $0.696$
\end{theorem}
