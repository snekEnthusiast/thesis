As shown before, relatively simple algorithms achive the optimal competitiveness of $1-\frac{1}{e}\approx0.632$. A natural question is to ask how to break this barrier. This is possible with a relatively small model change.

\begin{model}[Random Arrival]
	\label{model:random-arrival}
	The random arrival model is like the Semi-Online model, but has one crucial difference - vertices arrive in a random order instead of an adversarial one
\end{model}

In this section we will prove that both Ranking and RGA perform strictly better in the Random Arrival model than in the Semi-Online model

\begin{theorem}
	\label{thm:rga-ra-comp}
	In the random arrival model, RGA(\autoref{alg:RGA}) has a competitiveness of $1-\frac{1}{e}$
\end{theorem}

\begin{theorem}
	\label{thm:rank-ra-comp}
	In the random arrival model, Ranking has a competitiveness of at least $0.696$
\end{theorem}
